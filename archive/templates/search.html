Search all archived images, including object frames and calibration frames such as darks and flats. The center field accepts sky coordinates or a resolvable object name. With a radius, the result includes images whose frame centers are within that distance from the query position; without a radius, it includes images covering the query position.
Use the site, CCD, camera serial, filter, image type, target ID, night range, and filename fields to narrow the search. Night values use YYYYMMDD. Filename searches match any part of the filename; include SQL % wildcards for an explicit pattern.
